Secure Multi-Party Computation Protocol Architecture

1

Local Model Training

Raw aquaculture sensor telemetry stays local. Edge devices train gradient weights independently on local pond datasets.

2

SMPC Secret Sharing

Weight vectors are split into polynomial secret shares. Individual shares reveal zero statistical info on raw pond metrics.

3

Global Weight Synthesis

The central coordinator reconstructs only the sum of gradients, updating the global model without seeing individual node data.

About Us

Smarter feeding for healthier fish

AquaSmart is a smart aquaculture platform built as a summer internship project at SESAME Engineering School. It combines IoT water-quality data, machine learning and privacy-preserving federated learning to help fish farmers decide when to feed and how much.

By reading every pond's water quality in real time, the system reduces feed waste and protects fish health, while federated learning with secure aggregation keeps each farm's data private.
