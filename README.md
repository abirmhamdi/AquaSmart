# AquaSmart

Smart aquaculture platform for predicting fish feed rations using IoT water-quality data.

## Versions

- `AquaSmart-v1-ML/`: ML-only version, reserved for future upload.
- `AquaSmart-v2-FL-SMPC/`: Version implementing Centralized ML, Local ML, Federated Learning, and SMPC secure aggregation.

See `AquaSmart-v2-FL-SMPC/README.md` for detailed project documentation and installation instructions.
